# __APP_NAME__ (frontend)

React + Vite + Tailwind + TypeScript client for the FastAPI backend in `../backend` (generated by
[create-fastapi-app](https://github.com/SenZmaKi/create-fastapi-app)) with auth wired up.

```bash
npm install
npm run dev        # http://localhost:5173, /api proxied to BACKEND_URL
```

## Auth (mirrors backend `/api/auth/*`)

register → verify email (6-char code) → app. Also login/logout, `me`, resend code, forgot/reset password.
The backend returns the session token in the `Authorization: Bearer …` response header; `src/lib/api.ts`
stores and sends it. A 401 clears the session.

## Where to build

- `src/App.tsx` – routes; put app pages under `<ProtectedRoute verified />`
- `src/lib/api.ts`, `types.ts` – endpoints and DTOs
- `src/pages/Home.tsx` – replace with your app

## Production

`Dockerfile` builds static assets and serves them with nginx, proxying `/api/` to `BACKEND_URL`
(default `http://backend:8000`), so the browser stays same-origin. Or deploy `dist/` anywhere and set
`VITE_API_URL` to the backend URL plus its `CORS_ORIGINS`.
